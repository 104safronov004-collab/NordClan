При сборке проекта вы можете столкнуться с ошибкой:
**Совет для вас:**  
1. Обратите внимание на то, где лежит `Dockerfile` и какой путь указан в `docker-compose.yml`. Это поможет понять причину ошибки, если сборка не стартует.  
2. Проверьте порты, которые проброшены в docker-compose.yml, и порт, на котором слушает ваш сервер. Несовпадение может привести к тому, что сайт не будет доступен.
